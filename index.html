깃허브 유저네임(ID)과 개인 토큰(PAT)을 입력하여 트래픽 추적을 즉시 시작하세요.

개인 토큰(PAT)은 안전하게 보호됩니다
  • 서버 미전송: 토큰은 외부 서버나 DB로 절대 전송되지 않으며, 오직 본인 브라우저의 localStorage에만 보관됩니다.
  • 직접 통신: 외부 프록시 없이 본인 브라우저에서 깃허브 공식 API 서버(api.github.com)로 직접 데이터를 교신합니다.
  • 실시간 검증: 개발자 도구(F12)의 네트워크 탭에서 외부 유출이 없는지 직접 눈으로 검증하실 수 있습니다.
